# Local Setup & Verification Guide\n\nThis guide walks you through setting up the Business Manager App on your local machine.\n\n## Prerequisites\n\nBefore you start, ensure you have these installed:\n\n- **Node.js** 18+ (https://nodejs.org/)\n- **npm** 9+ (comes with Node.js)\n- **Docker** (https://www.docker.com/products/docker-desktop)\n- **Docker Compose** (included with Docker Desktop)\n- **Git** (https://git-scm.com/)\n\n### Verify Prerequisites\n\nRun these commands in your terminal to verify installations:\n\n```bash\nnode --version    # Should be v18.0.0 or higher\nnpm --version     # Should be 9.0.0 or higher\ndocker --version  # Should show Docker version\ndocker compose --version  # Should show Docker Compose version\n```\n\n## Step 1: Clone and Setup\n\n```bash\n# Clone the repository\ngit clone https://github.com/juzerzoebmarvi/business-manager-app.git\ncd business-manager-app\n\n# Switch to develop branch (if not already on it)\ngit checkout develop\n\n# Copy environment file\ncp .env.example .env\n```\n\n## Step 2: Start Docker Services\n\nStart PostgreSQL and Redis in the background:\n\n```bash\n# Start containers in detached mode\ndocker compose up -d\n\n# Verify containers are running\ndocker compose ps\n```\n\nYou should see output like:\n```\nCONTAINER ID   IMAGE                 STATUS\n...            postgres:16-alpine    Up X seconds\n...            redis:7-alpine        Up X seconds\n```\n\n### Troubleshooting Docker\n\nIf containers don't start:\n\n```bash\n# Check logs\ndocker compose logs postgres\ndocker compose logs redis\n\n# Stop and remove containers, then retry\ndocker compose down\ndocker compose up -d\n```\n\n## Step 3: Install Dependencies\n\nInstall npm packages for both backend and frontend:\n\n```bash\n# Install root dependencies and workspace dependencies\nnpm install\n\n# Verify installations\nls -la apps/api/node_modules\nls -la apps/web/node_modules\n```\n\n## Step 4: Start the Application\n\nStart both the backend API and frontend dev server:\n\n```bash\n# From the root directory, this runs both in parallel\nnpm run dev\n```\n\nYou should see output like:\n```\n> api@0.1.0 dev\n> nest start --watch\n[Nest] 12345  - 10/01/2026, 5:30:00 PM     LOG [NestFactory] Starting Nest application...\n\n> web@0.1.0 dev\n> vite\n  VITE v5.4.2  ready in 123 ms\n  ➜  Local:   http://localhost:5173/\n```\n\n## Step 5: Verify Everything is Running\n\n### Frontend\nOpen your browser and navigate to:\n```\nhttp://localhost:5173\n```\n\nYou should see:\n- Business Manager dashboard\n- Dashboard with stats cards (Revenue, Expenses, Outstanding, Inventory)\n- Recent activity section\n- Quick reports menu\n\n### Backend API\nTest the API is responding:\n\n```bash\n# In a new terminal\ncurl http://localhost:3000/api\n\n# Expected response:\n# Business Manager API is running\n```\n\n### Test Reports Endpoints\n\n```bash\n# Test supplier invoice report\ncurl \"http://localhost:3000/api/reports/supplier-invoices?fromDate=2025-01-01&toDate=2025-12-31\"\n\n# Test payment report\ncurl \"http://localhost:3000/api/reports/payments?fromDate=2025-01-01&toDate=2025-12-31\"\n```\n\nBoth should return JSON with mock report data.\n\n### Database Connection\n\nVerify PostgreSQL is accessible:\n\n```bash\n# Using psql (if installed)\npsql -U postgres -h localhost -d business_manager -c \"SELECT NOW();\"\n\n# Expected output: current timestamp\n```\n\nIf psql is not installed, you can test via Docker:\n\n```bash\ndocker exec -it business_manager_postgres psql -U postgres -d business_manager -c \"SELECT NOW();\"\n```\n\n### Redis Connection\n\nVerify Redis is accessible:\n\n```bash\n# Using redis-cli (if installed)\nredis-cli -h localhost -p 6379 ping\n\n# Expected output: PONG\n```\n\nIf redis-cli is not installed:\n\n```bash\ndocker exec -it business_manager_redis redis-cli ping\n\n# Expected output: PONG\n```\n\n## Step 6: Project Structure Verification\n\nVerify the folder structure is correct:\n\n```bash\n# From root, list the directory structure\ntree -L 2 -I node_modules\n\n# Or use ls on each directory\nls -la apps/\nls -la apps/api/src/\nls -la apps/web/src/\n```\n\nExpected structure:\n```\nbusiness-manager-app/\n├── apps/\n│   ├── api/              # NestJS backend\n│   │   ├── src/\n│   │   ├── package.json\n│   │   └── tsconfig.json\n│   └── web/              # React frontend\n│       ├── src/\n│       ├── package.json\n│       └── vite.config.ts\n├── docker-compose.yml\n├── package.json\n├── .env\n└── README.md\n```\n\n## Step 7: Frontend Functionality Test\n\n1. Navigate to http://localhost:5173\n2. Verify you see:\n   - Dark theme dashboard\n   - Stats cards showing Revenue, Expenses, Outstanding, Inventory\n   - Recent activity list (sample data)\n   - Quick reports section\n3. Click on \"Quick reports\" links (they are interactive)\n4. Check browser console for any errors: Press `F12` → Console tab\n\n## Step 8: Backend Functionality Test\n\n1. Test reports API endpoints:\n\n```bash\n# Terminal 3 (new tab)\n\n# Supplier invoices report\ncurl -s \"http://localhost:3000/api/reports/supplier-invoices\" | jq\n\n# Expected: Returns supplier invoice report data\n\n# Payment report\ncurl -s \"http://localhost:3000/api/reports/payments\" | jq\n\n# Expected: Returns payment report data\n```\n\n2. Test with custom date filters:\n\n```bash\ncurl -s \"http://localhost:3000/api/reports/supplier-invoices?fromDate=2025-02-01&toDate=2025-02-28&status=Open\" | jq\n```\n\n## Stopping the Application\n\nTo stop the dev servers:\n\n```bash\n# Press Ctrl+C in the terminal running npm run dev\n```\n\nTo stop Docker containers:\n\n```bash\n# Stop containers\ndocker compose down\n\n# Stop and remove volumes (WARNING: deletes data)\ndocker compose down -v\n```\n\n## Common Issues & Fixes\n\n### Issue: Port 5173 already in use\n```bash\n# Kill the process using port 5173\nlsof -ti:5173 | xargs kill -9\n# Then restart: npm run dev\n```\n\n### Issue: Port 3000 already in use\n```bash\n# Kill the process using port 3000\nlsof -ti:3000 | xargs kill -9\n# Then restart: npm run dev\n```\n\n### Issue: Docker containers fail to start\n```bash\n# Clean up Docker\ndocker compose down\ndocker system prune -a\n# Retry\ndocker compose up -d\n```\n\n### Issue: npm install fails\n```bash\n# Clear npm cache and retry\nnpm cache clean --force\nrm -rf node_modules apps/*/node_modules package-lock.json\nnpm install\n```\n\n### Issue: Module not found errors\n```bash\n# Ensure you're in the root directory and have run npm install\ncd business-manager-app\nnpm install\n```\n\n## Next Steps\n\nOnce you verify everything is working:\n\n1. **Database Schema**: Design and Add to backend\nnpm install <package> --workspace apps/api\n\n# Add to frontend\nnpm install <package> --workspace apps/web\n\n# Add to root\nnpm install <package>\n```\n\n## Verification
